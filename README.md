BetterBonk is an all-in-one quality-of-life mod for Megabonk, combining the features of a number of existing mods with some additional features and fixes using one combined GUI menu.
The purpose of the mod is that I wished to make some chagnes to the mods that i was using and whilst doing so thought it would be a good idea to have them in an all in one mod.

Main features
Quick Reset: (Smart Map Rerolling)
Automatically evaluates the current run's map at the start and either accepts it or resets for you — no more manually eyeballing spawns every run. This includes extensive customization and a preset/config system in the menu.

Auto Pot Breaking:
Automatically detects and breaks nearby pots for you as you play — tuned to match (and exceed) the range and speed of similar existing mods, without misfiring on other interactables (won't accidentally trigger curse shrines or other objects standing near a pot).

Personal Leaderboard:
Tracks your own run history locally, independent of the game's own stats.

Toggle Everything:
Integrates the popular "Toggle Everything" mod's functionality directly, letting you enable/disable unlocked items and weapons from the in-game menu
